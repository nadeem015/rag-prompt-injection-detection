## Determinism notes

* Only the bootstrap procedures (seed 42, 1000 resamples) and the simulation (seeds 42/123/456) use randomness; both are seeded with `numpy.random.default_rng`. McNemar tests, AUC/AP, always-flag and the rule/hybrid flags are deterministic.
* `all_predictions_with_rules_and_hybrids.csv` stores `rule_score` rounded to three decimals; AUC/AP use unrounded scores computed in memory (the independent script re-scores the texts).
* The stored joblib models were pickled with scikit-learn 1.8.0 and are loaded by 1.9.1 with a version warning; inference reproduced the stored probabilities to 2.2e-16.

## What was NOT reproduced (needs external access or the author)

1. **Model training** (`experiments/run_final_experiment.py`): reconstructed, never executed (needs Hugging Face access). The stored models, thresholds and per-example predictions of the author's original run are the evidence; the script was only checked to reproduce thresholds 0.47/0.60 from the stored validation sweep.
2. **Streamlit app**: `streamlit` could not be installed (package index unreachable); never launched. A stub-based smoke test exists and is labelled as such.
3. **Rule detector**: a reconstruction; the author's original module and its results are not available and are not reproduced.
4. **Dataset downloads and cards**: Hugging Face datasets could not be downloaded; the primary dataset's own card could not be fetched.
5. **Equation rendering in Microsoft Word** and the **IEEE PDF eXpress** check were not run.
6. **End-to-end LLM evaluation**: not performed; exposure in the simulation is a screening proxy, not attack success.
